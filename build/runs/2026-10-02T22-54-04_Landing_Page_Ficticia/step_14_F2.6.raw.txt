### APPEND: styles.css
```css
/* ========================================= */
/* 10. SECCIÓN ESTADÍSTICAS (R3)             */
/* ========================================= */

#estadisticas-animadas {
    background-color: var(--text-light); /* Fondo blanco para la sección de estadísticas */
}

/* Contenedor principal del grid de estadísticas */
.stats-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: var(--spacing-md); /* Espacio entre los elementos estadísticos */
    margin-top: 3rem;
}

/* Estilo de cada elemento estadístico individual */
.stat-item {
    background-color: #ffffff;
    padding: 2rem;
    border-radius: var(--border-radius);
    box-shadow: 0 4px 15px rgba(0, 0, 0, 0.08); /* Sombra más marcada */
    text-align: center;
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}

/* Efecto hover para los elementos estadísticos (destacar) */
.stat-item:hover {
    transform: translateY(-5px);
    box-shadow: 0 12px 25px rgba(0, 0, 0, 0.15);
}

/* Estilo del número grande (el contador) */
.stat-number {
    font-size: 3.5rem; /* Tamaño muy grande para impacto visual */
    font-weight: 700;
    color: var(--primary-color); /* Usamos el color primario como acento principal */
    margin-bottom: 1rem;
    /* Añadimos un efecto de transición suave al cambiar el número (JS lo manejará) */
    transition: all 0.5s ease-out;
}

/* Estilo del texto descriptivo debajo del número */
.stat-label {
    font-size: 1.2rem;
    color: #6c757d; /* Gris suave para la descripción */
    margin: 0;
    padding-top: 0.5rem;
    display: block;
}

/* Ajustes de Responsividad para Estadísticas (Móvil) */
@media (max-width: 768px) {
    .stats-grid {
        gap: 20px;
    }
    
    .stat-item {
        padding: 1.5rem;
    }

    /* Reducir el tamaño del número en móvil */
    .stat-number {
        font-size: 2.5rem;
    }

    .stat-label {
        font-size: 1rem;
    }
}
```
