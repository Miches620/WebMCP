### APPEND: styles.css
```css
/* ========================================= */
/* 7. ESTILOS DE SECCIÓN HERO (R1)            */
/* ========================================= */

.hero-section {
    background-color: var(--bg-light); /* Fondo suave para el hero */
    padding: 8rem 0; /* Padding generoso verticalmente */
    text-align: center;
}

.hero-content {
    max-width: 900px;
    margin: 0 auto;
    /* Usamos Flexbox para manejar el layout de forma más robusta, aunque actualmente solo haya contenido apilado. */
    display: flex;
    flex-direction: column; /* Por defecto, los elementos se apilan verticalmente */
    align-items: center; /* Centra horizontalmente todos los hijos */
    gap: 2rem; /* Espacio entre el título, subtítulo y botón */
}

/* Estilo del Título Principal (H1) en Hero */
.hero-section h1 {
    font-size: 3.5rem; /* Tamaño grande y impactante */
    color: var(--text-dark);
    margin-bottom: 0; /* Quitamos el margen inferior ya que usamos gap en .hero-content */
    line-height: 1.1;
}

/* Estilo del Subtítulo (P) en Hero */
.hero-section .subtitle {
    font-size: 1.35rem;
    color: #6c757d; /* Gris más suave para el subtítulo */
    margin-bottom: 0; /* Quitamos el margen inferior ya que usamos gap en .hero-content */
}

/* Ajuste de tamaño en dispositivos móviles y tabletas (Media Queries) */
@media (min-width: 992px) {
    /* En pantallas grandes, si tuviéramos una imagen a la derecha, podríamos usar grid/flex horizontal aquí.
       Por ahora, mantenemos el stack vertical pero lo hacemos más robusto. */
}

@media (max-width: 1200px) {
    /* Ajuste de tamaño para pantallas medianas */
    .hero-section h1 {
        font-size: 3rem; /* Reducción gradual del título */
    }
    .hero-section .subtitle {
        font-size: 1.25rem;
    }
}

@media (max-width: 768px) {
    /* Ajustes para pantallas de tablet y móviles */
    .hero-content {
        padding: 0 15px; /* Añadir padding lateral al contenido del hero */
    }
    .hero-section h1 {
        font-size: 2.5rem;
    }
    .hero-section .subtitle {
        font-size: 1.1rem;
    }
    /* Aseguramos que el botón no sea demasiado grande en móvil */
    .btn {
        width: 100%; /* Ocupar todo el ancho disponible para mejor toque */
        max-width: 300px;
    }
}

@media (max-width: 480px) {
     /* Ajustes específicos para móviles pequeños */
    .hero-section h1 {
        font-size: 2rem;
    }
    .hero-section .subtitle {
        font-size: 1rem;
    }
}
```

Nota: Se ajustó la lógica de espaciado en el Hero Section, pasando de márgenes fijos a usar `gap` dentro del contenedor flex para un control más limpio y moderno sobre los elementos apilados. También se añadieron media queries específicas para mejorar la escalabilidad del texto en diferentes tamaños de pantalla.
